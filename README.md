## 1. Giới thiệu tổng quan
**QuickBite** là giải pháp Web Application hỗ trợ đặt món trước (Pre-order) và quản lý luồng đơn hàng trực tuyến dành riêng cho khu vực căn tin tại các cơ sở Đại học Kinh tế TP. Hồ Chí Minh (UEH). Hệ thống giúp giải quyết tình trạng ùn tắc giờ cao điểm, cắt giảm thời gian chờ đợi của sinh viên từ 15 phút xuống dưới 3 phút và số hóa quy trình bán hàng cho quầy căn tin.

## 3. Công nghệ dự kiến sử dụng
- **Front-end:** HTML5, CSS3, JavaScript, TailwindCSS / Bootstrap (Mobile-web responsive nhẹ, mượt trên smartphone).
- **Back-end:** PHP / NodeJS (RESTful APIs).
- **Database:** MySQL Server.
- **Thanh toán:** Tích hợp sinh mã VietQR chuyển khoản ngân hàng tự động.
- **Quản trị dự án:** Jira Software, Microsoft Project 2016, GitHub.

## 4. Cấu trúc thư mục tài liệu
- `docs/`: Chứa các tài liệu khởi động dự án (Problem Statement, Project Charter, Stakeholder Register, Team Charter).
- `planning/`: Kế hoạch chi tiết theo từng Sprint tuần.

- `tests/`: Kịch bản kiểm thử (Test Cases) và tài liệu bảo đảm chất lượng QA.
