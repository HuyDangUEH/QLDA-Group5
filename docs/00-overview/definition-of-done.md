# Definition of Done (DoD)

Một User Story chỉ được coi là **Done** khi đáp ứng tất cả các tiêu chí sau:

- [ ] Code hoàn thành và đáp ứng đủ Acceptance Criteria
- [ ] Code đã được push lên repo và merge qua Pull Request
- [ ] Có ít nhất 1 thành viên khác review và approve
- [ ] Đã kiểm thử, không còn lỗi nghiêm trọng
- [ ] Tài liệu liên quan đã được cập nhật
- [ ] Product Owner đã xác nhận trong Sprint Review

# Definition of Ready (DoR)

Một User Story sẵn sàng đưa vào Sprint khi:

- [ ] Viết đúng mẫu: _Là [vai trò], tôi muốn [chức năng] để [lợi ích]_
- [ ] Có Acceptance Criteria rõ ràng
- [ ] Đã được ước lượng (Story Point)
- [ ] Đủ nhỏ để hoàn thành trong 1 Sprint
